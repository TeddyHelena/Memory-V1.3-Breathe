# Breathe 使用说明（截图手册）

本目录存放 MemoryV1.3-Breathe 的使用说明与截图手册，供安装后阅读。

| 文件 | 内容 |
|---|---|
| `usage-guide.html` | 使用截图手册：引导、面板三视图、记忆链操作，含 `shots/` 截图 |
| `usage.html` | 文字版使用说明：记忆与记忆链 |
| `index.html` | 配置说明书 |

## 版本与时效

- 制作时间：**2026-11-14**，对应 **0.16.3** 界面。
- 当前发布版为 **0.16.3+breathe.1120.5**，引导触发逻辑与面板首帧已调整：
  首装会正确弹出「认识一下」，截图中的部分文案与顺序可能与此版略有差异。
- 以实际界面为准；发现不一致欢迎提 issue。

## 如何查看

- 在 GitHub 上：点开对应 `.html` 文件后使用 **Raw** 下载，本地用浏览器打开。
