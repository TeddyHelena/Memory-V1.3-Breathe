这两处必须你亲手写。

有本机历史会优先参考摘要；没有就随机抽。选中不会自动保存。

我在这儿是什么位置？

这一条最要紧——它不是配置，是往后所有事的底。选一个。

我该怎么跟你说话？

选一个。这一段会进声音层，每轮对话强制生效。

我该是什么性子？

选一个。

事到你手上之前，我先怎么想？

这一组不互斥，最多挑三个。挑多了就成了空话。

我们怎么共事？

三件小事，各二选一。这三条决定我敢不敢拦你。

哪些是打死也不能破的？

默认全给你勾上了——这几条本来就不该是选项。要松掉哪条，自己点。

你希望的我是？

四道题，二选一。不用懂 MBTI——按你想要的相处方式答就行。

它要不要自己长？

这件事得你点头。没有默认值，选一个才能往下走。

打开之后会发生什么
  • 你和它的全部对话原样存在你自己机器上（一字不改，不裁剪不摘要）
  • 每三天，它会读一遍新对话，自己长出新的长期记忆
  • 你现在定的这几条（事实锚点 / 身份 / 底线…）永远不会被自动改，只你人工动
  • 随时可以关；已经存下来的，随时可以删
